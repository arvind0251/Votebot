# Telegram Vote Bot

A simple Telegram bot that allows users to create polls and vote.

## Features
- Start the bot using `/start`
- Create a poll using `/vote`
- Collect votes and display results

## Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Add your BOT_TOKEN in `config.py`
4. Run the bot: `python bot.py`
